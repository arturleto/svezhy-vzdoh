## СТРУКТУРА ПРОЕКТА
- `index.html` = копия `offer.html` — корневой URL открывает полную страницу напрямую (без отдельной видео-страницы)

- `img-*.png` — иллюстрации, генерируются через nano-banana (Gemini 2.5 Flash Image)

### Архитектура первого блока
- `video-block` + `hero-intro` обёрнуты в `.top-hero-wrap` с единым градиентом; сами блоки — `background:transparent`
- Если разделить на два блока с разными градиентами — будет видимая линия стыка (грабля!)
- `.hi-pillar` карточки: `background:rgba(255,255,255,.06)` — НУЖЕН тёмный фон-родитель, иначе белый текст невидим на белом

## КРИТИЧНЫЕ ПРАВИЛА

### Git / деплой
- **Перед пушем PNG-файлов** всегда делать: `git config http.postBuffer 52428800` — иначе HTTP 400
- Деплой = `git push origin main` → GitHub Pages обновляется автоматически (~1-2 мин)
- Кэш Telegram не сбрасывается сам — добавлять `?v=N` к URL для принудительного обновления превью

### Изображения
- Все PNG генерируются через `mcp__nano-banana__generate_image` (Gemini 2.5 Flash Image)
- Gemini всегда выдаёт квадрат 1024×1024; для 2:1 кадра — кроп через PIL
- Ресайз на macOS: `sips -Z <px> input.png --out output.png`
- **Для PNG-стикеров (без рамки):** генерировать на белом фоне → убирать фон flood-fill от углов (thresh=40), НЕ threshold по всему изображению — иначе съедает белые части арта
- **Для «бесшовного» наложения на тёмный фон:** генерировать с фоном точно #0D3826 — картинка сливается с фоном страницы

### Кириллица в Gemini
- Русский текст генерируется, но модель часто переносит слова на новую строку даже при явном запрете
- Лайфхак: перечислять буквы через дефис «С-В-Е-Ж-И-Й В-З-Д-О-Х» и просить «wide horizontal banner», «like a marquee sign»

### PNG — очистка внутренних белых
- После flood-fill внешнего фона оставшиеся белые opaque-пиксели = внутренность букв
- Убирать через numpy: `data[(a>30) & (r>200) & (g>200) & (b>200), 3] = 0`
- Апскейл логотипа: `img.resize((w*3, h*3), Image.LANCZOS)` — гладкие края без AI

## КНОПКИ — АНИМАЦИЯ БЛИКА (iOS Safari)
- `clip-path` обрезает `box-shadow` → тень пропадает
- `filter: drop-shadow` убивает анимацию `::after` на iOS
- Рабочая структура (как tw-btn): `overflow:hidden` + `border-radius` + `translateZ(0)` + `::after` с `translateX` (НЕ `left`)
- Анимировать `left` нельзя на мобильных — только `transform: translateX`
- Если на элементе есть своя `animation:` — `::after` анимация на iOS не работает

## ДИАГНОСТИКА (`diagnostika/`)
- Разделение: `config.js` — ВСЁ содержимое (вопросы, баллы, тексты, стадии), `index.html` — только движок. Тексты править в config.js
- **Палитра синяя** (05.08): фон `--bg:#070C16`, свечение `--glow`, акцент оставлен мятным `--acc:#A8E6C5` — связка с зелёным лендингом, куда человек уходит после. Увести акцент в синий = поменять только `--acc` / `--acc-dim` / `--acc-line` / `--on-acc`
- **21 вопрос на всех ветках** — цифра зашита в `INTRO.meta`. Меняешь состав вопросов → проверь скриптом и поправь цифру, иначе ложь на первом же экране
- **Мультивыбор** (`multi:true`): вариант с полем `p` прячется, если это основной продукт человека; `none:true` — взаимоисключающий. Потолок баллов у multi = сумма ДВУХ старших вариантов (не всех — иначе занизит проценты всем)
- **Прогресс считается по «оптимистичному» списку** (`activeList(true)`): вопросы с неразрешённым `showIf` идут в знаменатель заранее. Иначе счётчик стартует с 19, после ответа про попытки бросить прыгает на 21 и **полоска едет назад** — грабля 05.08
- Стартовый кредит прогресса `PROGRESS_BASE = 9%` + счёт `(n+1)/T`, а не `n/T`: после первого ответа полоска обязана двинуться
- **Пройденная диагностика залипает** в localStorage (`vzdoh_diag_v3`) и при заходе сразу открывает результат. Сбросы: адрес `.../diagnostika/?reset` (работает всегда) или отладочная ссылка внизу результата — `CONFIG.restartBtn`. **Перед запуском поставить `restartBtn: false`**
- Грабля 05.08: обработчики вешать ТОЛЬКО в `setTimeout(...,140)` после `paint()` — paint откладывает отрисовку на 130мс, если на экране уже есть кадр. У `screenIntro` обработчик стоял синхронно, и кнопка «Пройти диагностику» была мёртвой после «Назад» с первого вопроса
- Кнопка «Отправить результат Артуру» УБРАНА (05.08) — в финале ровно одна кнопка. Функция `payload()` осталась в коде на случай возврата отправки в бот
- Плейсхолдер «здесь будет видео Артура» УБРАН — в точке решения читался как «продукт сырой». Появится обратно сам, когда в `PROFILES[*].video` появятся файлы
- Payload в ссылке на бота (`d2…`) бот НЕ парсит (только `/start`) — порядок вопросов менять безопасно
- Интро должно помещаться в экран (~896px): sticky-кнопка перекрывает то, что ниже, пока не доскроллишь
- **Правки в config.js не видны на живом сайте** — браузер держит старый файл в кэше. Подключение версионировано: `config.js?v=N`, **бампать N при каждой правке конфига**. Разово помогает Cmd+Shift+R
- `.intro .cta-dock` переопределяет sticky-док на `position:static`: контента на интро мало, иначе между оффером и кнопкой полэкрана пустоты
- `img/free.jpg` (07.08) — освободившаяся девушка выходит из своей прошлой версии на нитях, вокруг серые курящие. Стоит в первой вставке «Сила воли тут не работает». Водяной знак Gemini (звёздочка в правом нижнем углу, bbox ~880–927) заретуширован патчем фона
- Картинки (07.08): `img/face-split.jpg` — разделённое лицо во вставке «Здоровье — самое ценное»; `img/breath.jpg` — «Свежий Вздох» в финальной вставке. **У всех генераций Gemini срезать водяной знак** — светлое пятно в правом нижнем квадранте, заливается патчем чистого фона с левого края
- **Тексты профиля не должны утверждать того, чего человек не отвечал.** Карточка «Почему срывались раньше» говорила о срывах тому, кто выбрал «ни разу не пробовал». У каждого профиля есть `whyNone` + заголовок «Где это обычно срывается» — то же знание, но как предупреждение. Появится новый профиль → писать оба текста
- **Доллары рядом с рублями** (`CONFIG.usdRate`, ф-ция `usd()`): аудитория не только из РФ. До $10 показываем десятую — иначе пачки за 150 ₽ и за 200 ₽ обе дают «$2» и варианты выглядят одинаковыми. ⚠️ Курс — оценка, обновлять раз в полгода
- Стаж «меньше года» = `years: 0.7`. Всё, что печатает число лет, обязано проверять `years >= 1` — иначе вылезает «за 0.7 год» (плюс отдельный `MONEY.outroShort` без «за эти годы»)
- Слово «сигарета» в текстах профилей оставлено намеренно (решение Артура 07.08): читается как обобщение для всех способов употребления. В НАЗВАНИЯХ категорий — «курение», их видят кальянщики и вейперы
